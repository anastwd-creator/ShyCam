i made this project because iam a shy person and introvert, i've always wanted to record myself and started a vloging ,
*and because i hate people looking at me ,so i made this app so i can pretend like im speaking with someone while recording .


HOW TO USE :
- open the app , click on import ref.
- chose any video you like to use  (like selfie video of someone speaking ,or video call recorder).
- click on callend icon to start recording (the mute microphone icon is a pause button).

                           OPTIONL : YOU CAN CHANGE SITTING OF THE OVERLAY.

FEATURES :
- video loop overlay with extra sitting .
- import any video from gallery and play it .
- icons are custom to look like a video phone call.
